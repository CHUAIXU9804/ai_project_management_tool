## The Architecture Workflow
The Main Functionality of the app
- Once an authorized user logged in, they should be able:
Integrate the application with gmail, Google Calendar, or Slack
- The application is able to: Ex. Gmail
    - Scan through emails from gmail
    - Analyze symantic meaning in each email, group similar email content together, if they (use some deterministic rules first):
        - Check if they come from the same email sender
        - Contain the same project name / keywords
        - Then use LLM to analyze the semantic meaning similarity / relationship between the messages (The messages don't necessarily have to be in the threads)
